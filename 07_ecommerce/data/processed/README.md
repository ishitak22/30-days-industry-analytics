# Processed Ecommerce Tables

This folder is generated by `07_ecommerce/scripts/01_build_analytics_tables.R`.

The real CSV tables are not committed until the original Olist source files have
been downloaded into `07_ecommerce/data/raw/` and the Phase 2 build has run.
Raw source files stay ignored by Git.

- `dim_customers.csv`
- `dim_products.csv`
- `dim_sellers.csv`
- `dim_date.csv`
- `fact_orders.csv`
- `fact_order_items.csv`
- `fact_payments.csv`
- `fact_reviews.csv`
- `customer_order_history.csv`
- `monthly_kpis.csv`
- `category_performance.csv`
