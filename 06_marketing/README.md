# 06 Marketing: Customer Campaign Response Classification

This project uses Databricks to build a customer campaign-response analytics workflow.

Planned components:
- GitHub and Databricks Git folders
- Unity Catalog
- Volumes
- Bronze, Silver, and Gold Delta tables
- Python, PySpark, and SQL notebooks
- Customer campaign-response classification model
- MLflow experiment tracking
- Prediction table
- Tableau dashboard
- Lakeflow Jobs orchestration
